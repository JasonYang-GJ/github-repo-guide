两种方式有什么区别？费用怎么算？
基础分析
按固定规则整理文档、代码结构和来源。不使用大模型，没有赠送或消耗的模型额度；阅读时会按顶部语言在本机自动翻译。
AI 深入解读
在相同读取范围内补充项目用途、适合人群和模块解释，按所选语言生成解读。由你填写的 API Key 所属账户计费；更详细不代表更准确。

两种方式都需要联网读取 GitHub，可能遇到访问次数限制，也会使用本机资源。GitHub 访问限额与模型 API 余额是两回事。

              这份报告是怎么来的
              
        
              
        
              
          
              01
              读取仓库
              记录本次提交版本，读取 README、配置和部分源码。大仓库不一定会读完。
              
          
              02
              整理来源
              将代码事实对应到文件和代码位置。文档介绍与 AI 解读会分别标注。
              
          
              03
              检查结果
              核对报告格式、引用和代码关系。检查通过不代表项目已运行或 AI 解读完全正确。
              
          
              04
              生成报告
              在页面阅读，也可下载 Markdown 说明、JSON 数据和 Mermaid 结构图。
              
        
              
      
              

      
              
        
              分析前，了解这几点
              
        
              目前只支持公开 GitHub 仓库。报告用于了解项目，不代替安装测试或安全审计。
              
        
              
          
              不会运行仓库代码
              只读取文本，不克隆仓库、不安装依赖，也不执行脚本或测试。仓库内容不会被当作操作指令。
              
          
              密钥由你保管
              供应商配置保存在当前浏览器；API 密钥由 Windows 当前用户加密保存在这台电脑，不写入报告或日志，也不会在页面回显完整内容。
              
          
              AI 分析单独计费
              使用 AI 时，仓库文本会发送给所选供应商，由你的 API 账户付费。模型生成失败时回退到免费报告，不自动付费重试。
